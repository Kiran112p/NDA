Title:
	Verify successful creation and saving of a software configuration on the Software Config page

Summary:

Steps:

Open the application and log in using valid credentials.
Navigate to the Device Management section.
Add a new device if required.
Click the Software Config tab.
Enter public_host in the Config Name field.
Enter This config changing the device host like private host to public host in the Config Description field.
Click the Next button.
Select ROUTER_NCS_540 from the Device dropdown.
Click the Next button.

Click the Next button.
Click the Save Configuration button.
