Test case: Add SSH private device and verify it appears

Preconditions:
     Browser is installed and working
     Application URL is accessible
     Valid login credentials exist
     User is not already blocked by prior test data
Summary:
        The user enters the password Kiran@112, scrolls down if necessary, selects IOS XR as the Device Type and 7.0 as the Device Version, clears the Host Name field and enters Private, then selects SSH as the Protocol.      Clear and enter Private for Host Name

Expected results:
