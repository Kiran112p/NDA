Test name
Create and verify a parallel software update job

Preconditions:
	Browser is installed
	Application URL is accessible
	Valid login credentials are available
	User can access the software update page
summary: 
      The user logs into the application, navigates to the Software Update page, uploads overview1.txt, selects 	all devices, and chooses Parallel as the installation type. After entering routers_Parallel_Update as the 	job name, the user starts the job and saves a screenshot. The file uploads successfully, the job is 	created successfully, and the jobs table shows Job Status = Completed and Run Status = Success.

Steps:
	Open the application and log in
	Confirm dashboard loads successfully
	Click the Software Update menu/icon (href="#software-update")
	Scroll down if needed
	Upload the file located at overview1.txt
	Wait until the uploaded file name appears in the UI
	Click Next or continue to step 2
	Select all devices by clicking the selectAllDevices control
	Choose Parallel from the installation type dropdown
	Click Next or continue to step 3
	Enter routers_Parallel_Update in the job name field
	Click Run now
	Click Start Job
	Save a screenshot of the job creation screen

Expected Results:
	The upload completes successfully and the file is shown in the UI
	The job is created successfully
	In the jobs table, the first row shows:
	Job Status = Completed
	Run Status = Success
	Optionally, a screenshot file is generated
